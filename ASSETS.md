# Asset provenance and reuse

This collection does not call assets “copyright-free.” Original code and generated images can also carry rights. The goal is to avoid redistributing unexplained third-party media and to make provenance explicit.

- **Unwallet v1 and v2:** existing assets are retained unchanged at the owner's explicit request. This includes token/protocol marks, partner graphics and the local Departure Mono font. The upstream Departure Mono MIT notice is included with each font. The root code license does not grant rights to third-party brands or artwork.
- **Exequatur:** unexplained abstract JPGs are replaced with a newly generated image. The procedural WebGL orb code remains. The generation prompt is in artwork/provenance.json.
- **Bidnox:** copied raster screenshots and thumbnails are replaced with original procedural sample art. Original product screenshots are not bundled in this reusable edition.
- **Shoal:** illustrations, team photos and external protocol graphics are replaced with procedural sample art and neutral labels.
- **Skech:** raster illustrations, photos and external graphics are replaced with procedural sample art. The local pixel-font binary is omitted; the fallback is monospace. Google-font declarations remain and fetch their fonts during the build.
- **Liquid:** original Unsplash photos, raster preview assets and embedded video files are omitted/replaced. The original credits page remains for attribution, with an added notice that this edition uses procedural sample art. Locally bundled SVG graphics are replaced with neutral originals. The library code and dependency license notices remain.
- **ErebuZ:** old reference captures, downloaded Namada artwork, external protocol marks and other raster assets are not redistributed. The reusable code uses original procedural images/neutral labels. Website layouts and code-based illustrations remain.
- **Piker (audited, not selected):** upstream landing repositories contain IPL/ICC team logos and a stadium image without provenance established in this audit. Do not infer permission to redistribute them. A new fictional stadium image is supplied at artwork/piker-stadium.png as a replacement option; use original neutral team names/initials for a reusable release. Piker source is not included in this collection.

## Generated work

The Exequatur and Piker images were generated with OpenAI's built-in image tool on 21 November 2026, with no input/reference images. Prompts exclude logos, named artists, real stadiums and recognizable protected characters. Generation does not itself guarantee exclusivity, copyright registration, or absence of third-party claims. Review assets for the intended use. No assertion of a blanket copyright exemption is made.

The deterministic SVG sample art is authored by this collection's replacement script. `asset-replacements.json` lists all affected paths. Do not run the replacement script in an original product repository.

Portfolio films are separate showcase media, not a redistributable stock-video/music library; they are not bundled here.
